README







getting images for cards is super easy barely an inconvenience:

1 Open STS2
2 go to card library
3 open a card
4 screen grab the card roughly in the art area
5 go into paint.net
6 use a select template that matches (or get the ones in resources/cards)
7 name that version 'cardname'_p
8 copy that card
9 make a new png file
10 scale that version by 50%
11 save and name that version 'cardname'
